## 🚀 How to Use

### Preview Locally
1. Open `index.html` in your web browser (Chrome recommended)
2. The website will load with all photos in a responsive gallery

### Deploy Online
1. Choose a static website host (e.g., Netlify, Vercel, GitHub Pages, Surge.sh)
2. Upload the entire folder or ZIP file
3. Ensure the `photos/` folder stays together with `index.html`
4. Share the live link with friends!
